# Midnight Shelf

파일을 옮기지 않고 메모와 태그로 정리하는 macOS 앱입니다.

[최신 버전 받기](https://github.com/midnightai-apps/midnightai-shelf-releases/releases/latest)

macOS 15 이상, Apple Silicon Mac을 지원합니다. DMG를 열고 Midnight Shelf를 응용 프로그램 폴더로 끌어 넣으세요.

0.0.15부터 자동 업데이트를 지원합니다. 도움말 메뉴에서 **업데이트 확인…**을 누르거나 **자동으로 업데이트 확인**을 켤 수 있습니다. 업데이트 설치는 앱에서 안내합니다.

0.0.14 이전 버전은 새 DMG로 한 번 설치해 주세요. 기존 메모·태그·모음집은 유지됩니다.

이 저장소는 설치 파일과 업데이트 피드만 배포합니다. 파일을 추가해도 원본 파일을 이동하거나 삭제하지 않습니다.
